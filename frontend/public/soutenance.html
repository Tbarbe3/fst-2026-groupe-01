Sécurité

Un projet sur la revue de code se doit d'être propre

🔑 Authentification

  • Better Auth, cookies Secure
  • Secret obligatoire en prod
  • Pas d'énumération de comptes

🚦 Limitation de débit

  • Auth : 20 req/min/IP
  • Génération : 15/h
  • trustProxy derrière Traefik

🧱 Entrées

  • Schémas Fastify sur chaque corps
  • SQL toujours paramétré
  • Corps limité à 64 Ko

🔒 Secrets

  • Clé Gemini en en-tête, jamais dans l'URL
  • Uniquement dans les .env
  • Helmet

Ce qu'on a appris

Les pièges de la mise en prod

Better Auth derrière un proxy

Sans trustProxy, l'URL reconstruite était en http : sessions rejetées.

Nginx vers un hôte fantôme

Un relais /api vers api:3000 inexistant : erreurs 502. Traefik route seul.

Gemini instable

Modèle retiré (404), saturé (503), lent (30 s). D'où la liste de modèles et le juge simulé.

Une démo sans clé

Mode mock : catalogue dans les 7 langages, juge par mots-clés, zéro jeton.
